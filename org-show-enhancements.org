#+TITLE: org-show enhancements: beamer columns, title pages and more
#+OPTIONS: toc:2 num:nil ^:{}

This file describes the changes made to =org-show.el= so that an Org file
written for beamer export can be presented directly in Emacs.  The original
org-show documentation is in [[file:org-show.org]].

* Overview

The enhanced org-show adds:

- *Beamer columns side by side*: frames with =:BMCOL:= / =:BEAMER_col:=
  children are shown as a title strip above one window per column.
- *Images fitted to the column*: plots are drawn by org-show itself and
  scaled to the width and height of their window.
- *Text fitted to the slide*: text shrinks until each column fits, and
  size changes carry over to later slides.
- *Aligned tables*: tables are aligned to what is displayed, including
  expanded macros, equation images and proportional fonts.
- *Reflowed paragraphs*: hard-wrapped source lines are joined on screen, as
  LaTeX would do.
- *Clutter hidden*: property drawers, =#+NAME:=, =#+RESULTS:=, =#+ATTR_*:=
  lines, non-exported source blocks and raw LaTeX lines are not shown.
- *Equations sized to the text*: LaTeX math is previewed at the size of
  the text and follows it as the text is fitted, and beamer-only
  =#+LATEX_HEADER:= lines no longer leak into the equation images.
- *Macros expanded*: ={{{macro(...)}}}= is shown as its expansion, and a
  macro can be given its own definition for the show.
- *Title page and section pages*: generated (and animated) from =#+TITLE=,
  =#+AUTHOR=, =#+DATE= and from the headings above the slides.
- *Beautification during the presentation only*: org-modern,
  variable-pitch text and hidden emphasis and macro markers are switched on for
  the presentation and turned off afterwards.
- *COMMENT headings skipped*, as in beamer export.

* Preparing a presentation

** Slides
A slide is a heading with the =:slide:= tag.  For a beamer file with
=#+OPTIONS: H:2=, tag every level-2 heading:

#+begin_example
,* Section title
,** Frame title                                                     :slide:
#+end_example

Add =tags:nil= to =#+OPTIONS= so the tag is not printed in the beamer output:

#+begin_example
,#+OPTIONS: toc:nil H:2 tags:nil
#+end_example

To tag all level-2 headings of a file at once, evaluate this in the file's
buffer:

#+begin_src emacs-lisp
(org-map-entries (lambda () (org-toggle-tag "slide" 'on)) "LEVEL=2")
#+end_src

Slides under a =COMMENT= heading (or with =COMMENT= in their own
heading) are skipped, so the presentation has the same frames as the
PDF.  Un-commenting a heading brings its slide back, since it keeps
its tag.

** Columns
Columns are written exactly as for beamer: children of the slide heading with
a =BEAMER_col= property (or the =BMCOL= tag).

#+begin_example
,** Title                                                           :slide:
,*** Left                                                           :BMCOL:
:PROPERTIES:
:BEAMER_col: 0.5
:END:
[[file:image-8.png]]

,*** Right                                                          :BMCOL:
:PROPERTIES:
:BEAMER_col: 0.45
:END:
+ First point
+ Second point
#+end_example

The column widths on screen are proportional to the =BEAMER_col= values.  A
column without a width gets an equal share.  Text between the slide heading
and the first column is shown in the title strip.

** Title page
The title page is made from these keywords:

| Keyword       | Shown as        |
|---------------+-----------------|
| =#+TITLE:=    | title (bold)    |
| =#+SUBTITLE:= | subtitle        |
| =#+AUTHOR:=   | author (italic) |
| =#+DATE:=     | date (italic)   |

LaTeX in these values is tidied up: =\\= starts a new line, =\today= becomes
today's date, =\and= becomes a comma, and other commands are dropped while
their text is kept.  Empty keywords are left out.  Without =#+TITLE=, the
file name is used, as beamer does.

** Section pages
A section page is shown before the first slide under each heading that sits
above the slides, e.g. each level-1 heading when the slides are level-2
headings.  A section whose slides are all commented out gets no page.

* Running the presentation

** Starting and stopping
| Command                           | Does                                    |
|-----------------------------------+-----------------------------------------|
| =M-x org-show-start-slideshow=    | start at the beginning (the title page) |
| menu /org-show → Open this slide/ | start at the slide containing point     |
| =M-x org-show-stop-slideshow=     | stop and restore the buffer             |

Stopping removes the column windows and their buffers, un-hides
everything, turns off the beautification modes that the presentation
turned on, and widens the buffer.

Note: starting and stopping realign all tags in the buffer, which marks it
as modified.  Only whitespace changes.

** Keys
These are active while =org-show-mode= is on (it is turned on by
=org-show-start-slideshow=):

| Key       | Command                              |
|-----------+--------------------------------------|
| =PgDn=    | next slide                           |
| =PgUp=    | previous slide                       |
| =F5=      | start the presentation               |
| =F6=      | show the current slide again         |
| ~C-=~     | larger text (this and later slides)  |
| =C--=     | smaller text (this and later slides) |
| =M-ESC g= | go to slide number                   |
| =M-ESC t= | table of contents                    |
| =M-ESC q= | stop the presentation                |

The keys work from any window, including a column window.

** Table of contents
=M-ESC t= lists all slides, including "Title page: …" and "Section: …"
entries, as links.  Clicking a link goes to that slide; =q= closes the list.

** Editing during the show
The column windows presentation indirect buffers of the presentation file, narrowed
to the column.  Their text is the file's text, so edits made during the show
go straight into the file.

* How slides are displayed

** Layout
- The frame is split into a *title strip* (the heading) and one window per
  column, with mode lines hidden.
- Slides without columns use a single window, as before.
- Title and section pages use a separate buffer, =*org-show-page*=, with the
  text centred.  If =org-show-animate-pages= is on, the lines are animated
  in; any key press skips the animation.

** Images
Image links (=[[file:plot.png]]=) are drawn by org-show with their own
overlays.  Each image is scaled down to at most
=org-show-image-width-fraction= of the window width and
=org-show-image-height-fraction= of its height.

This does not depend on =org-image-actual-width= or on scimax's own inline
image code, which ignored the widths set for the presentation.  When the presentation stops,
the normal Org inline images are shown again.

** Text size
Each slide starts at its maximum text scale and shrinks one step at a time
until everything fits in its window.  All columns of a slide get the same
scale.

- The maximum scale is =org-show-column-text-scale= for columns and
  =org-show-text-scale= for slides without columns.
- ~C-=~ and =C--= change that maximum by one step from the size currently on
  screen, so the new size applies to all later slides.
- Text never grows beyond what fits.  To allow text that overflows the
  window, set =org-show-fit-text= to nil.

** Equations
LaTeX math (=$...$=, =\(...\)=, =\[...\]=, =$$...$$= and environments
such as =equation= or =align*=) is previewed as images, as with =C-c C-x
C-l=, and laid out for the slides:

- *Sized to the text*: equations are shown at =org-show-latex-size= (0.8)
  times the size of the text font.  The 10pt LaTeX font is matched to the
  text font by measuring a preview image, so this works with any font,
  with =variable-pitch-mode=, and whatever =:scale= is set in
  =org-format-latex-options=.  Use 1.0 for math as large as the text.
- *Follows the text*: equations grow and shrink with the text of the
  slide, when the text is shrunk to fit and with ~C-=~ / =C--=.  Since they
  are sized before the text is fitted, a slide with large equations gets a
  smaller text size instead of running off the window.
- *Sharp*: the images are rendered at =org-show-latex-scale= (4.0) and
  displayed smaller.  With =dvisvgm= (SVG) they are sharp at any size; with
  =dvipng= a higher render scale gives sharper but slower images.
- *Left aligned*: display equations start at the left margin, like the
  text.  Set =org-show-center-display-math= to =t= to centre them in the
  window or column, as LaTeX does.  Inline math always stays in the text.
- *Own lines*: display equations inside a paragraph keep their own lines
  when the paragraph is rewrapped.
- *Never wider than the window*: numbered environments such as =equation=
  are as wide as a LaTeX page, since the number is at the right margin, so
  they may be shrunk to fit.  For big equations, use =equation*= or
  =\[...\]=.
- *Named equations*: an environment with a =#+NAME:= line is shown; the
  name line is hidden with the other clutter.
- *No beamer settings in the images*: Org previews equations with the
  article class, but adds the file's =#+LATEX_HEADER:= lines.  Beamer
  commands there, such as =\setbeamersize{description width=0.1cm}=, are
  unknown to article, and LaTeX prints their arguments in every equation.
  During the show, lines matching =org-show-latex-preview-drop-regexp=
  (=\setbeamer...=, =\use...theme=, =\AtBegin...=, =\logo=,
  =\titlegraphic=, =\institute=) are left out of the preview preamble.
  Other headers, such as =\usepackage{amsmath}= or =\newcommand=, are kept.
  Outside the show, =C-c C-x C-l= still uses the full preamble.

When the presentation stops, the equation images are removed, since
they were made for the slides; press =C-c C-x C-l= to preview again.  The
images are cached (in =ltximg/=, see =org-preview-latex-image-directory=),
so a slide is slow only the first time it is shown.

For example, for slightly larger, centred equations in one presentation:

#+begin_example
,#+ORG_SHOW: latex-size:1.0 center-math:t
#+end_example

** Macros
Org macros (={{{name(arguments)}}}=) are shown on the slides as their
expansion, with overlays, so the file is not changed.  Many macros expand
to LaTeX that means nothing on screen, so a macro can be given a separate
definition for the show.  The expansion is chosen in this order:

1. A =#+ORG_SHOW_MACRO:= line in the file, written like a =#+MACRO:=
   line.  Beamer and other exporters ignore it.  For example, to show only
   the text of a cell-colour macro:

   #+begin_example
   ,#+MACRO: cc @@latex:\cellcolor{$1}$2@@
   ,#+ORG_SHOW_MACRO: cc $2
   #+end_example

2. An entry in =org-show-macro-templates=, in the configuration.  The
   template is a string like the above, or a function that gets the
   arguments and returns the text to show, which may have faces.  For
   example, to show the text on a coloured background:

   #+begin_src emacs-lisp
   (setq org-show-macro-templates
         '(("cc" . (lambda (color text)
                     (propertize text 'face `(:background ,color))))))
   #+end_src

3. Org's own expansion, as in export: the =#+MACRO:= definitions and the
   built-in macros (={{{title}}}=, ={{{author}}}=, ={{{date}}}=,
   ={{{time(%Y)}}}=, ={{{n}}}=, ={{{keyword(...)}}}=,
   ={{{property(...)}}}= and so on).  Export snippets for other back-ends,
   such as =@@latex:...@@=, are left out.  The contents of
   =@@org-show:...@@= snippets are kept, so one =#+MACRO:= line can also
   carry its show version:

   #+begin_example
   ,#+MACRO: cc @@latex:\cellcolor{$1}$2@@@@org-show:$2@@
   #+end_example

A macro whose expansion is empty (like =cc= above with no show
definition) or that is not defined at all is left as it is, with its
braces hidden (=org-show-hide-macro-markers=).

Expansions are shown as Org text: =*bold*= and =/italic/= in an
expansion look as they do on the slide, and macros inside an expansion
are expanded too.  Macros in =#+TITLE=, =#+AUTHOR= etc. are expanded on
the title page.  =#+MACRO:= definitions that evaluate Lisp (=(eval
...)=) are not expanded, so starting a show never runs code from the
file; use =org-show-macro-templates= for those.  Tables with macros stay
aligned, see [[*Tables][Tables]].

To turn expansion off, set =org-show-expand-macros= to nil (or
=#+ORG_SHOW: macros:nil=).

** Tables
Org aligns a table by the characters in the file, but on a slide a cell
can show something of another width: an expanded macro, an equation image
(=$\times$=), or text in a proportional font.  During the show, every Org
table is aligned to what is actually displayed: the width of each cell is
measured in the window, and the blanks around it are shown as space of the
right width, so the =|= separators line up.  Numbers, which Org aligns to
the right, stay right-aligned, and horizontal rules are drawn to the column
widths.  This is redone whenever the text size changes.

Only the display changes; the file is not.  To keep Org's own layout, set
=org-show-align-tables= to nil (or =#+ORG_SHOW: align-tables:nil=).

** Paragraphs
Line breaks inside a paragraph are displayed as spaces, so hard-wrapped
source text is rewrapped to the column width.  The file is not changed.

** Lists
Lists are laid out with overlays, so the file is not changed:

- *Bullets by depth*: unordered items get the bullets in
  =org-show-list-bullets= by nesting depth, whatever bullet character
  (=+=, =-=, =*=) is used in the file.  The default ='("●" "○" "■" "□")=
  gives =●= for items, =○= for sub-items, and so on, starting again from
  the first for deeper lists.  Numbered items keep their numbers.
- *Indentation*: sub-items are indented by =org-show-list-indent= (4)
  spaces per level, in the text font, so the indentation scales with the
  text and is clear even in proportional text.
- *Wrapped lines*: when an item wraps, the following lines start under
  the item's text, not at the left margin (=org-show-hanging-indent=).

The bullets use the face =org-show-bullet= (the level-1 heading colour,
bold, 1.3 times the text height).  For example:

#+begin_src emacs-lisp
;; arrows and dashes
(setq org-show-list-bullets '("➤" "–" "•"))

;; more indentation per level
(setq org-show-list-indent 6)

;; bigger bullets (in use-package, :custom-face works in any load order)
(use-package org-show
  :custom-face
  (org-show-bullet ((t :inherit org-level-1 :weight bold :height 1.5))))
#+end_src

** Hidden clutter
When =org-show-hide-clutter= is non-nil, the following are hidden:

- property drawers
- =#+NAME:=, =#+RESULTS:=, =#+CAPTION:= and =#+ATTR_*:= lines
- source blocks with =:exports results= or =:exports none= (their results,
  such as plots, stay visible)
- =emacs-lisp-slide= blocks
- standalone raw LaTeX lines such as =\vspace{-0.5cm}= (but not the lines
  of equations, such as =\begin{equation}=)
- blank lines left at the top of a column
- the =:slide:= tag

* Beautification

During the presentation, org-show turns on the minor modes in
=org-show-beautify-modes= in the slide buffers, and hides emphasis and
macro markers.
They are turned off when the presentation stops, unless they were already on
before.  Normal editing is not affected.

The default, ='(org-modern-mode variable-pitch-mode)=, gives:

- styled headings, from [[https://github.com/minad/org-modern][org-modern]]
- larger, coloured list bullets that change with depth: =●= for items, =○=
  for sub-items, then =■= and =□= (=org-show-list-bullets=, face
  =org-show-bullet=); see [[*Lists][Lists]]
- proportional text, from the built-in =variable-pitch-mode=
- =*bold*= shown as *bold* without the asterisks
  (=org-show-hide-emphasis-markers=)
- macros that are not expanded (see [[*Macros][Macros]]) shown without their
  braces, e.g. =cc(red,text)= (=org-show-hide-macro-markers=, which turns
  on =org-hide-macro-markers=)

The bullets replace org-modern's own (small) ones only during the show;
org-modern is unchanged elsewhere.

Some modes are turned *off* during the presentation and back on when it stops:
those in =org-show-disable-modes=, by default =org-indent-mode= (from
=org-startup-indented=), whose heading-level indentation and wrap prefixes
spoil the list layout, and =display-line-numbers-mode=, since line
numbers do not belong on slides.

org-modern's tag labels are turned off during the show, since they would
show part of the hidden =:slide:= tag.

Modes that are not installed are skipped silently.  org-superstar and
org-bullets are not needed with org-modern, which does the same and
more.  org-appear only helps while editing.

** Turning parts of it off
Put any of these in the configuration (or evaluate with =M-:=), then start
the presentation again:

#+begin_src emacs-lisp
;; plain org, no beautification at all
(setq org-show-beautify-modes nil)

;; org-modern only, fixed-width text
(setq org-show-beautify-modes '(org-modern-mode))

;; variable-width text only, no org-modern
(setq org-show-beautify-modes '(variable-pitch-mode))

;; keep the bullets as they are (org-modern's own, if it is on)
(setq org-show-list-bullets nil)

;; keep line numbers during the presentation (only turn off org-indent)
(setq org-show-disable-modes '(org-indent-mode))

;; keep the *, /, = emphasis markers visible
(setq org-show-hide-emphasis-markers nil)

;; keep the {{{ }}} around macros visible
(setq org-show-hide-macro-markers nil)
#+end_src

Note: in variable-pitch text, code blocks can lose their alignment.  Tables
are re-aligned during the show (see [[*Tables][Tables]]).

* Per-file settings

Every setting below can be set globally (e.g. in =use-scimax.el=) and
overridden for one presentation from inside its Org file, in two ways.

** The =#+ORG_SHOW:= keyword
Put one or more lines like this near the top of the file:

#+begin_example
,#+ORG_SHOW: modern:nil variable-pitch:t bullets:("➤" "–") image-width:0.7
,#+ORG_SHOW: animate:nil column-scale:1
#+end_example

The syntax is that of =#+OPTIONS=: =key:value= pairs separated by spaces,
with the values written as Lisp (=t=, =nil=, numbers, strings in double
quotes, lists in parentheses).  The keyword is read each time a show starts,
so changes take effect at the next start.  When the show stops, the previous
values come back.  Beamer and other exporters ignore the keyword.

| Key              | Setting                                               | Value                      |
|------------------+-------------------------------------------------------+----------------------------|
| =modern=         | add or remove =org-modern-mode= in the beautify modes | =t= / =nil=                |
| =variable-pitch= | add or remove =variable-pitch-mode=                   | =t= / =nil=                |
| =modes=          | =org-show-beautify-modes=                             | list of =...-mode= symbols |
| =disable=        | =org-show-disable-modes=                              | list of =...-mode= symbols |
| =emphasis=       | =org-show-hide-emphasis-markers=                      | =t= / =nil=                |
| =macro-markers=  | =org-show-hide-macro-markers=                         | =t= / =nil=                |
| =macros=         | =org-show-expand-macros=                              | =t= / =nil=                |
| =align-tables=   | =org-show-align-tables=                               | =t= / =nil=                |
| =bullets=        | =org-show-list-bullets=                               | list of strings, or =nil=  |
| =list-indent=    | =org-show-list-indent=                                | number                     |
| =hanging=        | =org-show-hanging-indent=                             | =t= / =nil=                |
| =title-page=     | =org-show-title-page=                                 | =t= / =nil=                |
| =section-pages=  | =org-show-section-pages=                              | =t= / =nil=                |
| =animate=        | =org-show-animate-pages=                              | =t= / =nil=                |
| =page-scale=     | =org-show-page-text-scale=                            | number                     |
| =text-scale=     | =org-show-text-scale=                                 | number                     |
| =column-scale=   | =org-show-column-text-scale=                          | number                     |
| =title-scale=    | =org-show-title-text-scale=                           | number                     |
| =min-scale=      | =org-show-min-text-scale=                             | number                     |
| =fit=            | =org-show-fit-text=                                   | =t= / =nil=                |
| =image-width=    | =org-show-image-width-fraction=                       | number                     |
| =image-height=   | =org-show-image-height-fraction=                      | number                     |
| =clutter=        | =org-show-hide-clutter=                               | =t= / =nil=                |
| =latex-size=     | =org-show-latex-size=                                 | number                     |
| =latex-scale=    | =org-show-latex-scale=                                | number                     |
| =center-math=    | =org-show-center-display-math=                        | =t= / =nil=                |

Unknown keys and invalid values are skipped with a message in the echo
area, and the show starts anyway.  For safety, =modes= and =disable= only
accept symbols whose names end in =-mode=.

** File-local variables
The usual Emacs mechanism also works, with a block at the end of the file:

#+begin_example
# Local Variables:
# org-show-column-text-scale: 1
# org-show-list-bullets: ("➤" "–")
# org-show-section-pages: nil
# End:
#+end_example

These are read when the file is opened, so after changing the block, re-open
the file (=M-x revert-buffer=).  The simple settings (on/off flags, numbers
and the bullet list) are marked safe, so Emacs does not ask about them.
=org-show-beautify-modes= and =org-show-disable-modes= are not, since a file
could use them to turn on any mode; Emacs asks before using them (answer =!=
to accept a value permanently).

** Precedence
=#+ORG_SHOW:= overrides a file-local variable, which overrides the global
value.  A size changed with ~C-=~ / ~C--~ during the show changes the value
that is in effect (the local one if there is one).

* Tips

- *Re-evaluating =org-show.el= does not reset variables.*  =defvar= keeps
  a value that is already set.  To pick up a new default, use =M-x
  eval-defun= on that =defvar=, =setq= the variable, or restart Emacs.
- *Changing slides during a show*: after adding, removing or
  reordering slides, restart the presentation (or run
  =org-show-initialize=) to rebuild the slide list.
- *Beamer export is unchanged*: the =:slide:= tag is hidden by
  =tags:nil=, and =BMCOL= is handled by ox-beamer as before.
